## 4. 典型证据（原书页 vs 数据）

### 4.1 1431 年 户部/礼部（原书正文 p466 / PDF 481）

原书：户部 = 郭敦（四、乙巳、十一,卒）、郭資、黃福、胡濙（正、己卯、十四,禮尚兼掌）；
礼部 = 胡濙（兼掌戶部）。

数据：

```
1431 戶部 胡渙  注「四、乙巳、十一、卒正、己卯、十四、禮尚兼掌」
1431 戶部 郭敦  （注空）   1431 戶部 郭資（空）  1431 戶部 黃福（空）
1431 禮部 胡渙  「正、己卯、十四,兼掌戶部。」
```

→ 郭敦的卒注与胡濙的兼掌注被合成一条挂到「胡渙」；胡渙/胡濙是两个正字。

### 4.2 1433 年 户部（p468 附近）

原书：郭資卒，「十二、甲寅、五,卒,追封湯陰伯,謚忠襄」。数据把这条注挂在「胡濙」名下，
郭資条目注空 → 卒年/离任挂错人。

### 4.3 1449 年 兵部（原书 p484 证据页）

于謙注：「…八、戊辰、廿,兵右侍遷;八、壬戌、十五,死難。…」——"死難"是鄺埜（同格另一人），
不是于謙；数据未拆分，段首注混入他人事件。

### 4.4 1399/1400 年 御史府

数据：景清注 = 「二月,左僉都遷,尋改北平參議。練子寧二月,任。」；練子寧没有独立条目。
→ 多人同格未拆开，后一人被并进前一人注文。

### 4.5 断段：胡濙（禮部）

```
1426–1430 / 1432–1437 / 1439 / 1441 / 1443–1455 / 1457…  （8 段）
```

原书为宣德元年起 continuous 礼部尚书（至天顺元年）；缺口年多为 1 年交替，
是"无标签续页/多格行"丢行造成，不是真实离任。

### 4.6 伪人名 / 简繁 / 重复

- 伪人名 39：`井八年閏`、`劉中敷閏`、`夏原吉扈駕`、`右侍`、`趙班扈駕` …
- 简繁：`吴中`、`吕震`、`于谦`（应为吳中/呂震/于謙）
- 重复条目 25 组：如 1408 刑部 劉觀/吕震 两条同注「禮尚改」；1434 胡濙两条空注

### 5.3 前置阻断（数据层）❌

**在 B1–B3 修完之前，任何 UI 接入都会把错误"画得更漂亮"：**

- B1 多格名注错配（259 条可疑 + 1431/1433/1449/1399 实例）→ 抽屉原文/离任原因会错；
- B2 假断段（282 段）→ 时间轴出现大量假缺口，直接违反"可溯源"；
- B3 伪人名/未归一（39+286 人）→ 搜索/人物页出现"右侍""夏原吉扈駕"；
- B4 CBDB 错挂（5+21）→ 抽屉跳错 CBDB 人物页；
- B5 分期衙署未归一（御史臺/御史府/都察院、京儲/倉場）→ 泳道分裂。

| 问题 | 答复 |

## 9. 校正：不同衙署不合并（2026-10-18，老板指出）

老板指出「部门怎么可以合并？不同的部门好吧」——此前 B5 把
**御史臺/御史府→都察院**、**總督京儲→總督倉場** 合并，属错误，已回退。

### 9.1 查证

| 来源 | 原文/要点 |
|---|---|
| [《明會要》卷33·都察院](https://www.shidianguji.com/zh/book/7461917686017032255/chapter/1kp04frz910yq) | 洪武十三年五月，罷御史臺；十五年，更置都察院；建文元年，改都察院為御史府；成祖復舊制 |
| [《吾學編·皇明百官述》](https://www.shidianguji.com/zh/book/CADAL02081590/chapter/1lchvh9eg7y1u) | 吳元年設御史臺；洪武十三年罷御史臺；十五年改都察院；建文二年改御史府；靖難後復故 |
| [《中国官制大辞典》"总督仓场"](https://mall.cnki.net/reference/R2006050170004698.html) | 明置总督仓场一人，掌在京及通州等处仓场粮储，以户部尚书或侍郎充任 |
| [高寿仙《明代京通二仓述略》](http://cn.obj.cc/article-7174-1.html) | 京仓/通仓分设；总督仓场公署掌京通二仓，宣德五年李昶以户部尚书专督仓场 |
| 张德信原书部院表 | 表头本身有「總督京儲」（1431–1550、1553–1555 等）、「總督倉場」（1551）、「總倉場」（1557 后）之别；同一栏前后异名，原书未统一 |

**结论**：御史臺/都察院/御史府是同一监察机构在不同时期的**不同衙署表头**；
總督京儲/總督倉場/總倉場在原书里也是**不同表头**。无论是否同一机构改名，
**数据层一律按原书表头各立一衙，不合并**；沿革关系只写入文档，不进数据、
不做分组统计。

### 9.2 已执行的更正

- `office` 恢复为 **11 个独立衙署**：吏部、戶部、禮部、兵部、刑部、工部、
  御史臺、都察院、御史府、總督京儲、總督倉場；

  沿革关系只写入文档；

- 原第 8.1 节 B5「收敛 8 个」与 D31「衙署收敛为 8 个」以本节/D32 为准。
