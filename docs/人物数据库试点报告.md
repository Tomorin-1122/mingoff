# 人物数据库：字段抽取试点报告

> 2026-10-18。目标：从正文条目抽取「姓名 / 生卒 / 字 / 号 / 籍贯 / 科举 / 谥 / 出处」，
> 组装成人物表。本轮只做试点，验证可行性与准确度，不铺全量。

## 一、抽样与口径

| 项 | 数值 |
|---|---|
| 抽样 | 963 页中每 30 页取 1，共 **33 页** |
| 抽出条目 | **303 条**（9.2 条/页） |
| 全书参照 | 9,651 人 / 963 页 = 10.0 条/页 —— 切分密度基本吻合 |

切分规则：上一条出处以 `)` 或 `卷/页` 收尾，紧跟「2–4 汉字 + 字/號/名/（生卒）/，X人」即新条目。
无括号的引文（如 `圖繪寶鑑6/6`）也算收尾，否则条目会粘连。

## 二、名称门槛：先过滤再入库

303 条里只有 **180 条（59.4%）** 的人名能在《明人傳記資料索引》目录或 CBDB 里找到。
其余 40.6% 是切分噪声，例如：

```
一獨      乙乙邦才    原名鳳苞    光光時亭    樞子
```

这些不是人，是上一条的残尾或标题碎片。**结论：人物入库必须带名称门槛**
（目录 / CBDB 二选一），否则会灌进四成垃圾。

## 五、已知问题

1. **切分仍有四成噪声**，靠名称门槛兜住，但会连带丢掉真人（目录漏收的）；
2. **出处只解到「卷/頁」**，题名与书名的切分还粗（`王公神道碑銘(芳洲文集7/18下)` 可拆，但长题名会串）；
3. **谥号（9.2%）与本名（0.7%）覆盖低**，属原书体例，不必强求；
4. **同名多人**：CBDB 有 4,033 个目录名对应多人，人物表须留 `cbdb_id` 可空、并标 `ambiguous`。

## 七、字段校验：顾宪成案（2026-10-18 20:20）

用户抽查发现「顧憲成」的科举年显示为「弘治」，而他实为**萬曆八年（1580）进士**。
排查后确认是两处缺陷叠加：

1. **OCR 把「萬曆」认成「萬爵」**——「爵」不在年号表里，正则没命中；
2. **条目越界**——正文切片把下一位「顯聶（1476—1545）…弘治九年進士」也带了进来，
   正则一路滑到别人的科举年上，于是显示「弘治九年」。

修复三处：

| 修复 | 做法 |
|---|---|
| 小传内定位 | 科举只在「姓名 → 第一个出处括号」之间找，不跨到别人的小传 |
| 年号变体 | `萬[曆歷爵层]`、`万[曆歷]` 一律归一为「萬曆」 |
| 生年一致性 | 科举公元年 < 生年+12（或 > 卒年+2）判为串行，整条科举字段置空 |

修复后：

```
顧憲成  p957  1550–1612  萬曆八年(1580) 進士  字叔時 號涇陽 無錫  諡端文
張居正  p525  1525–1582  嘉靖二十六年(1547) 進士
王守仁  p28   1472–1528  弘治十二年(1499) 進士
徐階    p466  1503–1583  嘉靖二年(1523) 進士
```

全库校验：**0 条**出现「科举年早于生年+12」；带合法公元年的记录 3,138 条（48.4%）。
CSV 新增「科举年(公元)」列，便于人工快速核对。

**教训**：单字段正则必须限定在「本人小传区间」内，且要有跨字段一致性校验；
否则一处 OCR 错字会把整条记录带偏到别人身上。

## 八、与 CBDB 逐字段对账：这本书到底有没有价值

先纠正一个定位错误：**CBDB 不是裁判，是标尺**。本书的任务不是复述 CBDB，
而是补它没有的东西（文集出处、字号、谥、非官员）。对账的意义在于分清
「真冲突」与「互补」。

对象：人物表 6,487 人中能对上 CBDB 编号的 **2,801 人**，逐字段比对。

> **口径注（2026-10-18 D38 复核）**：`person_db.json` 中 `cbdb_kind=unique` 实为
> **2,805** 人（none 473 / multi 3,209），与本节 2,801 差 4 人。差在「能取到可比字段」
> 还是在跑报告后被改过，需要重跑 `mrzj_reconcile.py` 才能定；本报告数字先维持原样，
> 归档测试 `tests/test_mrzj_assets.py` 以 2,801–2,805 区间钉住，不做静默改写。


| 字段 | 一致 | 冲突 | 冲突率 | **本书独有** | CBDB 独有 |
|---|---|---|---|---|---|
| 生年 | 769 | 13 | **1.7%** | 125 | 121 |
| 卒年 | 759 | 11 | **1.4%** | 119 | 326 |
| 科举年 | 1,087 | 14 | **1.3%** | 125 | 229 |
| 字 | 1,673 | 160 | 8.7% | 142 | 204 |
| 籍贯 | 1,812 | 304 | 14.4% | 321 | 228 |
| 号 | 855 | 160 | 15.8% | 194 | 176 |

**核心事实高度吻合**：生卒、科举的冲突率只有 1.3–1.7%（769 对 13、1,087 对 14）。
这说明 OCR 与字段抽取是可靠的，也说明这本书本身靠谱。

**籍贯/号冲突高，但抽样后多不是史实冲突**：

```
籍贯  于若瀛  本书「山東濟寧」  CBDB「濟寧州」   → 口径（省名/州名）
籍贯  丁懋遜  本书「富化」      CBDB「霑化」     → OCR 形近
号    方弘靜  本书「采山」      CBDB「釆山」     → 异体字
号    王汝魯  本书「確齊」      CBDB「確齋」     → 异体字
号    顧憲成  本书「涇陽」      CBDB「景逸先生」 → 互补：顾宪成两号并存
```

最后一条最关键：**冲突 ≠ 错误**。顾宪成号泾阳、又号景逸，两边各记一个，
合并后信息更全。这正是「多源校勘」应有的样子。

### 本书的净增量

| 增量 | 规模 |
|---|---|
| 文集出处（篇名 + 书名 + 卷 + 页） | **7,468 条**，覆盖 3,302 人，涉 2,685 种书 |
| 本书独有字段值（生卒/籍贯/字号/科举） | **1,026 个** |
| CBDB 完全没有编号的人物 | **3,686 人**（6,487 − 2,801） |

「谁的墓志铭在哪本文集第几卷」这一层，CBDB 的 `BIOG_SOURCE_DATA` 给不了，
只能靠这本书。这是不可替代的部分。

**结论**：校对没有白做。对账分出的 304 + 160 + 160 条冲突，恰恰是下一步
要人工仲裁的对象——校对的产出就是这个仲裁清单，而不是「和 CBDB 一样」。
