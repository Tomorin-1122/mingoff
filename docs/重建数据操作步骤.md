## 步骤（在 `guji-pipeline/` 父目录执行，PYTHONPATH 指向 mingoff/src）

```powershell
python _scratch/rebuild_parse.py       # 解析 → _scratch/vol1_entries_raw.json
python _scratch/rebuild_canon.py        # 人名归一 + (year,person) 去重 → vol1_entries_canon.json
python _scratch/rebuild_cbdb_final.py   # CBDB 定稿 → vol1_entries_final.json / vol1_person_cbdb.json
python _scratch/rebuild_tenures.py      # 切段 + 月/离任 + D15 → _scratch/vol1_tenures.json
python _scratch/build_official_v3.py    # 组装 → mingoff/src/mingoff/data/official_cabinet.json
cd mingoff; $env:PYTHONPATH="src"; python -m mingoff.official   # 仓库内正式管线（从数据资产重建）
python -m mingoff.build_person_profiles # CBDB → person_profiles.json（抽屉人物小传）
```

> 注：`rebuild_parse.py` 的 `BOOK_PATCH` 含原书页补录（1403 解縉/1408/1412 胡廣/
> 1424/1479–81/1515/1567 徐階/1609–11）；`rebuild_canon.py` 会对归一后人名做
> `(year, person)` 去重（实测 1402 解縉、1441 曹鼐）。

## 关键口径

- 年表为「年在位」体：某年列名 = 该年在任；**无注文也入库**（旧版 bug 的根因）。
- 起月 = 注文里明确的入职事件月；无入职事件时退回本年纪月并降置信度
  （0.6/0.7），不冒充“精确到月”。
- 离任原因取注文离任动词；跨年引用（“正統元年十、…卒”）不算本年事件。
- 1644 年三月后的任命一律剔除（D15）；末任截到 1644.3 并打 `end_clamped`。
- CBDB 无可靠候选 → `cbdb_id = NULL`，不硬挂（当前 7 人，含 2 名南明）。
