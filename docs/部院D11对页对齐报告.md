# 部院 D-11 对页续行对齐报告（第一轮）

> 2026-10-19。任务：把对页无标签年的行→衙归属做成**可审计的对齐**，替代解析层无凭据的「顺序兜底」。
> 本轮只做**分析与验证**，不改数据；数据修正方案见文末（待老板拍板）。
> 脚本：`scripts/pilot/d11_align.py`（对齐）+ `d11_crosscheck.py`（反向验证）；产物
> `src/mingoff/data/vol1_buyuan_d11_review.json`（1,353 行建议）+ 本目录核对输出。

---

## 一、问题界定

部院年表 1544–1559 段为「一页带标签、一页不带」的对页交替版式（普查报告实测 140/134）。
解析层对无标签年用「三级锚定」（人名锚→按序补→顺序兜底），D40 已证实**兜底会整行错挂**（1548 等 9 处）。
D11 的目标：把 277 年里**全部 136 个无标签年**（1,353 行）的归属依据显式化、可复核。

---

## 二、方法

1. 从 OCR markdown 按年份头切表，逐行识别：首格是标签词 → 带标签行；否则无标签行；
2. **人名锚**：行内人名在已有数据里有 ±4 年的同衙记录 → 按 (人,衙) 出现频次给建议，conf = 占比；
3. **行序兜底**：无人名锚时按邻页（优先 +1 年）标签序列对位，conf 固定 0.3；
4. 与现有数据交叉验证：只取 conf≥0.9 的人名锚行，逐人比对当前数据 office。

---

## 三、结果

| 项 | 值 |
|---|---|
| 无标签年 | **136 个**（1350s 15 / 1400s 24 / 1450s 25 / 1500s 25 / 1550s 25 / 1600s 22） |
| 对齐行 | **1,353 行** |
| 人名锚 / 行序兜底 / 无依据 | 611 / 579 / 163 |
| 置信 ≥0.9（可直接采信） | **351 行** |
| 置信 0.5–0.9（建议回原书抽验） | 204 行 |
| 置信 <0.5（必须页核） | 798 行 |

**交叉验证（关键）**：conf≥0.9 的人名锚行与现有数据逐人比对——**405 人全部一致，0 错挂**。
即：**现有数据里人名锚能覆盖的部分没有错**；D40 发现的错挂全部落在「无人名锚、只靠行序兜底」的行。

---

## 四、结论与数据修正方案（待老板拍板）

1. **人名锚行（611 行，其中 351 行 conf=1.0）**：与现有数据 0 冲突，**不需要改**；
   这套锚定建议可固化进 review 文件作为出处依据。
2. **行序兜底行（579 行）**：D40 已抓到 9 处实证错挂。方案二选一：
   - **A. 回原书页核**（按 D-08 页表直取，约 579 行 ÷ 8 行/页 ≈ 73 页，估 1–1.5 天）——彻底；
   - **B. 显式降级**：全部 579 行打 `office_status="row-order"` 标记，站点虚线/灰显，
     置信文档声明「行序推断，未页核」——先上线后补核。
3. **163 行无依据行**（整行无锚无名，多为空行/纯注文行）：维持现状，不参与锚定。

**我的建议**：**先 B 后 A**——B 立即可做（一行代码 + 测试），让「哪些行是猜的」变成显式数据；
A 按页核节奏走 D-08 页表，核一年清一年。
