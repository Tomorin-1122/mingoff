# 部院 D-08 页码索引（2026-10-18）

> 目标：给 1368–1644 每一年建 `year → book_page / pdf_page` 索引，供 D-03 逐页核与站点「回原书页」。
> 产物：`src/mingoff/data/vol1_buyuan_pages.json`（277 年，100%）。
> 条目 `book_page` 覆盖 **3,317/3,317**；tenure 带 `start_book_page`/`end_book_page`。

---

## 1. 方法

1. 取部院大臣年表 PDF 页范围 **417–694**（正文 402–679，偏移 +15）；
2. 每页裁顶部 22% 标题条，用 RapidOCR（4 进程并行）识别年份；
3. 标题 OCR 失败的年再用「相邻年 ±1 页」补齐（1401、1609 两例，人工核为 450/659）；
4. 写成 `{year: {pdf_page, book_page}}`，book_page = pdf_page - 15；
5. 由 `buyuan_repair` 给每条条目写 `book_page`，`official_buyuan` 写 tenure 起止页。

---

## 2. 结果

| 项 | 值 |
|---|---|
| 覆盖年份 | **277/277（1368–1644）** |
| 页码条目覆盖 | **3,317/3,317（100%）** |
| 页面锚点 | 1368→p417(book402)、1440→p490(book475)、1644→p694(book679) |
| 特殊补齐 | 1401→p450、1609→p659（标题 OCR 失败，邻页推） |
| 排除页 | 410–416 为殿阁段，不纳入部院索引 |

---

## 3. 用途（D-03）

- 原书核对从"按公式猜页"变为**查表直取**：如 1539→PDF589/book574、1620→PDF670/book655；
- D-03 第二批已据此补 1369/1539/1541/1620；
- 剩余 117 条长缺口可按年直接取页，逐页核效率提升；
- 站点后续可给每条 tenure 提供「回原书 pXXX」链接。

---

## 4. 已知限制

- 标题 OCR 对个别模糊页（1401/1609）需人工补；已在 JSON 中记录；
- `book_page` 是**年份页**，不是人物具体行；精确到行仍需页面定位；
- 若原书一年跨两页（如 1449），索引取首个年份页，第二页需按相邻页另查。
