## 二、行结构（关键发现：行数不恒定）

行 = 官职，格 = 该年该职在任者（可多名、可跨行迁转）。抽样各时期行数：

| 正文页 | 年份 | 行数 | 行构成 | 标签列 |
|---|---|---|---|---|
| 402 | 洪武元年 1368 | 7 | 吏/户/礼/兵/刑/工/御史臺（御史大夫） | **有** |
| 405 | 洪武四年 1371 | ~7 | 同上（无标签，靠行序） | **无** |
| 422 | 洪武二十一年 1388 | 7 | 吏/户/礼/兵/刑/工/**都察院**；**户部整行空白** | 有 |
| 484 | 正统十四年 1449 | **8** | 七卿 + **總督京儲** | 有 |
| 555 | 正德十五年 1520 | **9**（末两行或为一行拆二，待 OCR 验证） | 七卿 + 待辨 | 无 |
| 625 | 万历十八年 1590 | 8 | 七卿 + 1（行序待锚点核） | 无 |
| 645 | 万历三十八年 1610 | 9 | 七卿 + 2（**孫瑋连续两行**，一人任两职） | 无 |
| 655 | 万历四十八年 1620 | 8 | 七卿 + 1；**年份头带注**（光宗即位等事件） | 无 |
| 679 | 崇祯十七年 1644 | 8 | 七卿 + 都察院；离职注含"死/降" | 无 |

要点：

1. **不能假设恒 7 行**。已知变体：御史臺→都察院（洪武十五年，1382）；
   總督京儲（正统–景泰间临时行）；其他临时增行待 OCR 后逐页归因。
2. **标签列时有时无**。带标签页可直接归类；无标签页按「最近带标签锚点页 + 行序 + 名人锚点」恢复行→官职映射（殿阁 5.3 已验证的策略），歧义行进待校清单。
3. **同名跨行**：年内迁转者（王瓊：兵部→吏部）会在两行出现；一人兼任两职（孫瑋）也在两行。`(year, person)` 唯一性校验（G4）需放行"同人多行"，以 office 维度为准。
4. **空行 ≠ 无行**：洪武二十一年户部整行空白，是原书"该年无载"，解析必须保留行结构（O3 行完整）。
5. **年份头带注**：万历四十八年头注「八,丙午,一,光宗即位;…」是事件注，不能当人名行解析。
6. **注文跨年高频**：趙世卿注含「四十三年正…卒。四十六年…」（1610 页注 16–46 年后事），切分名/注后，跨年事件不计当年（规范反模式 6）。
7. 御史臺时期行名为「御史大夫」，早期一格可纵向列二人（1368 湯和、鄧愈）。
