## 二、三个方向（按性价比排序）

| 方向 | 内容 | 价值 | 成本 |
|---|---|---|---|
| A. 纵深 | 殿阁衔、首辅、离职原因、月份精化 | 把现有 192 段从"色块"变成"有等级的官场" | 低（殿阁已 OCR） |
| B. 横向 | 中书省 → 部院七卿 → 南京 → 督抚 → 布政/科举 | 从"内阁站"变成"职官数据库" | 高（OCR+解析+版式） |
| C. 体验 | 检索、人物页、筛选、对比、发布 | 让数据可用、可分享 | 中 |

顺序：**A → B（先七卿）→ C → 继续 B**。理由：
1. A 里最贵的 OCR 已经跑完（殿阁 254 表已在 `_scratch/mineru_neige/`），只差解析；
2. A 能直接回答上一轮悬着的「首辅」问题（殿阁表是原书对班次的记录）；
3. B 的每一种表都要新 OCR + 新版式测绘，必须先有 A 验证过的解析范式；
4. C 放后面，是因为页面结构会随 A/B 变，早做会返工。

## 三、分阶段计划

### P0 收尾与立规（本轮，已完成）
- 产出：数据 v3、站点、`数据接入规范.md`、`年表PDF_OCR规范.md`；
- 验收：156 项测试全过，`pnpm build` 通过；
- 状态：✅。

### P1 中书省试点（14 页，OCR 规范首次实战）
- 范围：册1 正文 1–14（洪武元年–十三年，1368–1380）；
- 产出：`vol1_zhongshu_entries.json` + 解析器 + 证据图；
- 站点：画布左端 1368–1380 显示「丞相/平章政事/参知政事」层（与内阁层不同色）；
- 验收：13 年无缺年；胡惟庸（左丞相，洪武十三年伏诛）、徐達（右丞相）等锚点对上原书；
  O1–O5 + G1–G5 全过；
- 估算：0.5–1 天（OCR 14 页，排队另计）。
- 意义：用最小样本把《年表PDF_OCR规范》跑通，再上大表。

### P2 殿阁衔 + 首辅（价值最高，OCR 已就绪）
- 范围：册1 正文 103–400（殿阁 254 表，**已 OCR**）；
- 产出：
  1. `vol1_diange_entries.json`（年 × 殿阁 × 人；含迁转注文）；
  2. 首辅派生表（每年最高殿阁的在任者；年内更替按注文月份）；
  3. 校勘：与《明史》卷109/110 宰辅年表逐年对照，差异入 discrepancy 清单；
- 站点：内阁色块按殿阁衔着色/加角标；首辅加金色描边；抽屉显示「殿阁履历」；
  另：殿阁表覆盖 1382（洪武十五年置殿阁大学士）–1644，可把画布左侧
  1382–1401 补成「殿阁大学士（非内阁机务）」层，避免左侧长期空白；
- 验收：殿阁实际设置年（1382–1644）覆盖 ≥95%（缺年逐条归因）；首辅在崇祯 17 年
  基准 100% 对上 `chongzhen_offices.json`；抽样 20 个年份与《明史》一致；
- 估算：解析 1.5–2 天 + 校勘/UI 1 天。
- 风险：殿阁表版式最复杂（标签列丢失、跨页续行），必须按规范先测绘后写码；
  首辅规则（最高殿阁 + 入阁先后）要写进 DECISIONS，不靠名单顺序。

### P3 部院大臣（七卿）扩展
- 范围：册1 正文 401–680（部院大臣·京师，280 页）；
- 产出：`vol1_buyuan_entries.json`（六部 + 都察院等），站点加「部院层」与筛选；
- 验收：六部/都察院逐年覆盖；与《明史》卷111/112 七卿年表抽查一致；
- 估算：OCR 2 天（排队）+ 解析 1.5 天 + UI 1 天。
- 说明：侍郎（681–980）、京卿（981–1266）放 P6，避免一次摊太大。
- **2026-10-18 更新**：部院 v1 已交付并接收为 review baseline（1,417 段 / 841 人 /
  3,319 人-年），但独立质检发现名注错配、假断段、伪人名、CBDB 错挂等阻断项；
  **站点接入暂缓**，修复计划见 [部院数据接收报告](部院数据接收报告.md)。

### P4 人物页与检索
- 产出：人物页（跨官职履历轴：内阁 + 部院 + 殿阁 + CBDB 小传 + 实录命中）；
  全站检索（人名 / 官职 / 年号 / 年份）；
- 验收：任一人物可从时间轴、检索、外链三处进入；履历可回原书页；
- 估算：2–3 天。

### P5 发布
- 产出：静态站部署（GitHub Pages / Vercel）、自定义域名、数据下载页（JSON + 许可）、
  版本号与更新日志；
- 验收：公网可访问、移动端可读、无控制台错误；
- 估算：0.5–1 天。
- 前置：P2（首辅）完成后再发布，避免"发布即改结构"。

### P6 长线（按需）
- 南京部院/京卿（册2）、督抚（册3）、布政/按察/提学/科举（册4）；
- 月份精化（实录逐条校勘）、离职原因结构化、事件层；
- 每一表种独立登记、独立校验，不合并口径。
