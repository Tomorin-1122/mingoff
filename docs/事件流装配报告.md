## 二、装配算法

年表是「年在位」体：某人某年出现在表里 = 该年此人在任。故：

1. 按 (人, 职类) 聚合在任年 → 连续年份合并为段
2. 段首年的入职事件（含「兼東閣大學士入」等定式）→ `start_month`
3. 段末年的离任事件（罷/卒/致仕/削籍…）→ `end_month`
4. 无事件者仅到年，**month 留 NULL 不臆造**（D4 纪律）
5. `confidence`：起讫都有事件 0.8 / 单边 0.7 / 多年在任 0.6 / 单年无事件 0.5

## 三、质量校验

- 跨度 >50 年：**0**；时间倒挂：**0**
- 崇祯朝首辅序列与《明史》吻合（劉鴻訓 1628.10 罷、錢龍錫 1629.12 致仕、周延儒 1641 復召）
- 同人同年在「內閣 + 翰林院」并记 = 年表体例（兼职双记），非重复数据

## 四、已知边界

- 起月覆盖 30%：年表多数年份只记「某年某人任」，未载月起讫——不推断
- 段首尾若年表起点即已任（如册1 开篇），start 实为「可见起点」而非就任年
- 翰林院段含大量台阶官，与内阁段并记；做统计时应按 section 过滤
