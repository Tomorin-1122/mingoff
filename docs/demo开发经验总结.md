## 一、前端：无限画布的四个深坑（全部实测踩过）

本轮最大的架构变更是把"压缩进一页的时间轴"改成**月格等宽无限画布**
（195 格 × 26px ≈ 5200px，横向滚动）。这里面的坑比预想多得多：

### 坑 1：sticky 的 containing block 不随溢出延伸

`body` 不撑开宽度时（画布只是"溢出"），`position:sticky; left:0` 的元素
**永远不会吸附**——它的参照系只有视口宽的 body。
**修法**：`body{width:max-content; min-width:100%}`，让 body 真实宽度 = 画布宽。

### 坑 2：100vw + overflow clip = 页面卡死

修坑 1 时给页头加了 `width:100vw`——**100vw 不含纵向滚动条宽度**，页头比视口
宽 15px，撑出横向溢出；再配 `overflow-x:clip` 把根元素的横向滚动条剪没了。
结果：滚轮、拖动全部失效，页面"卡死"。
**教训**：同一问题上 sticky 和 100vw 互相打架时，换方案，不要叠补丁。

### 坑 3：fixed 才是页头的终极答案

页头/滑块最终用 `position:fixed; left:0; right:0` 钉死视口，与横向滚动彻底解耦；
图表区用 `padding-top: var(--fixed-h)` 补偿占位（JS 实测高度写入 CSS 变量，
resize 时重算）。**无限横滚场景下，页头别用 sticky，直接 fixed。**

### 坑 4：一张图只能有一套坐标系（本轮最贵的教训）

断限线"怎么挪都差 132px"折腾了三轮，最后发现是**单位不统一**：

- 职官条用**百分比**，基线是 track 宽（画布宽 − 标签列 132px）
- 断限线/年月列线/年龄格用**像素**，基线是 board（含标签列）

两套坐标差整整一个标签列宽。**修法**：全部改像素（`格号 × SLOT_W`），
`pctSlot` 只留调试。**规则**：凡是叠在同一个画布上的几何元素，定位单位必须统一；
只要有"标签列 + 数据区"两段式布局，像素就比百分比可靠。

### 附：贯穿列线会盖住吸左标签

贯穿整图的年/月列线是后 append 的绝对定位元素，天然盖在 sticky 标签之上，
标签看起来"透明"。**修法**：列线容器 `z-index:2`，标签 `z-index:5`。

## 二、前端：交互细节

- **月格游标**：滑块 `step=1` 即一月，range = 总月格数（195）；键盘 ←/→ 逐月步进
- **皇帝行年龄**：年龄带必须与红条**错位**（朱字压朱底会隐身）；只写"17岁"不写年份（轴上有）
- **同人联动**：悬浮某人任一条，其跨行所有任职条变墨色（与 `:hover` 同款）
  ——**不要描边**（突兀）、**不要淡化其余条**（整页闪烁伤眼）。墨色实底最安静有效
- **干支每年都标**：一年 312px 放"1636 丙子"两行绰绰有余，不必省字

## 三、数据：中研院检索的隐藏机制（本轮最大发现）

### `output.php` 的完整结果藏在 `out` 字段里

页面表格**只渲染前 5 条**，但 HTML 里有个
`<input type="hidden" name="out" value="…base64…">`，
base64 解码后是**完整结果表格**（"更多明實錄結果…"按钮提交的就是它）。

实测对比（楊嗣昌）：可见表格 5 条，out 里 **71 条**（崇祯朝 64 条）。
只解析可见表格 = 丢掉 93% 的数据。**修法**：优先解码 `out`，无结果再退回表格。
重抓后总量 543 → **5227 条**。

> 这个发现直接把月份覆盖率从 10% 拉到 33%（起月）/ 19%（迄月）。
> 抓任何"分页"站点前，先看隐藏字段里有没有完整数据。

### 月份在哪：出處列的年号纪年

`明實錄 附錄 崇禎實錄 卷十 崇禎十年 五月`——月份在**出處列尾部**，
不在时间列。解析正则的坑见 `shilu.py` 注释（閏月、年号选择分支）。

### 正则字符类 vs 选择分支（又踩一次）

`[一二三四五六七八九十]` 漏了「**元**」——「崇禎**元**年」全军覆没（74 条 era_year=None）。
汉字数字匹配要么补全字符类，要么用 `(十[一二]?|[一二三四五六七八九]|元)` 分支。

## 四、数据：回填纪律（宁缺毋滥）

实录命中 ≠ 就任记录。一个词（如"兵部尚書"）一年命中十几条，
哪条是就任、哪条是升迁/调任/议事，**必须读原文**。脚本只做一件事：

> 某人某年**恰有一条**带月记录，且该年恰是 tenure 的起/迄年 → 回填，打
> `*_from_shilu` 标记；同年多月（167 处）一律不回填，留给人工校勘。

配套字段：
- `start_month_leap / end_month_leap`：闰月标记，抽屉显示「閏十一月」
- `end_clamped`：区分"史料记为 3 月"与"因断限截到 3 月"（防虚报精度）

这三类"有月份"在 UI 上必须分开陈述：实录回填 / 年表口径 / 断限截断。

## 五、闰月：不设独立格（评估结论）

崇祯朝 17 年只有 7 个闰月。为它们打破"每年 12 格等宽"（D16）不值得：
- 闰年格数变多 → 各年不等宽 → 游标/年龄格/刻度全要按变宽年重算
- 闰X月在历法上位于X月之后，独立格（排十二月后）反而是**历法错误**
- 现行方案（记入同名平月格 + 抽屉标「閏」+ leap 字段留证）不损失信息

**重评时机**：将来做农历逐日视图再说。

## 六、构建与工具链备忘

- **路径 parents 层级**：`export_demo.py`（在 `src/mingoff/`）取仓库根要用
  `parents[2]`；本 session 在 `backfill_months.py` 上连错两次（parents[1] 是
  `src/`）。**规则**：写完先 `python -c "print(Path(__file__).resolve().parents[N])"`
  验一下再往下写
- **PowerShell 下 curl 是 Invoke-WebRequest 别名**：`-e` 参数会撞车。
  一律用 `curl.exe`
- **超长 POST body**：命令行放不下（WinError 206），写临时文件用
  `curl --data-binary @file`
- **重跑脚本前先看断点续传**：`fetch_months_for_demo.py` 支持增量（已抓的人跳过）；
  但改了解析逻辑后必须**删掉缓存重抓**（本次删了 `sinica_months.json` 重跑）
