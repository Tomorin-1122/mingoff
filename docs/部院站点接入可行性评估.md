## 二、必须动的前端（Timeline.tsx，873 行）

1. **行组件重构**（核心工作量）：`CabinetRow` 是硬编码单衙组件 → 参数化为 `OfficeRow({office})`，
   外层按 12 衙循环。数据流（assignLanes/span/月格）不变。
2. **泳道与高度**：12 衙共 **47 泳道 ≈ 1,128px** 轨道高（现行内阁 10 泳道 ≈ 264px）——
   页面高 4 倍。三个选项：①纵向自然滚动（最简单）②衙署折叠/展开 ③衙署 tab 切换。
3. **渲染量**：1,198 bars（现 192）——React memo + 泳道结构下 1,200 个 DOM span 无压力。
4. **灰显样式**：`office_status ∈ {row-order, mixed}` 加虚线边框/降透明度类 +
   抽屉声明「行序推断，未经页核」（方案 B 的 UI 兑现）。
5. **同名显示**：bar 标签与抽屉用 `person_label`（顧佐#1/#2、吳山#1/#2 等需可区分）。
6. **抽屉**：`PROFILES[person]` 缺时已优雅返回 null ✓；office 行改为显示该段 `office`。
