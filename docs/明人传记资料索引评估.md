# 《明人传记资料索引》调研与价值评估

> 调研对象：`D:\大一學年\大一下课程\历史文献学\历史文献学作业\明人传记资料索引.pdf`
> 调研日期：2026-10-18
> 结论速览：**高价值工具书，定位为「人物校勘 + 出处层」（L4），不建议整段搬入主数据；
> 建议先做 167 名内阁人物 + 5 名 CBDB 未对齐人物的定向提取（Phase 1）。**

---

## 0. 一句话结论

这是一部 **1965 年初版、1978 年再版**的明代人物传记资料索引，收 528 种明清文集、
65 种史传笔记，**每人先给一段小传（生卒、字号、籍贯、科举、职官、著作），
再列传记资料出处（篇名 + 文集/史传卷页）**，书后附**字号索引**。
对 MingOff 的直接价值有三层：**补 5 个 CBDB 未对齐人物的小传**、
**给 167 名内阁人物加「史料出处」层**、**用字号索引扩充别名表**。
它不是「又一本明史」，而是把「这个人有哪些传记材料、在哪本书哪一卷」讲清楚的工具书。

## 3. 体例与条目结构（对项目最重要的一节）

### 3.1 一条记录长什么样

以正文 p19「王一寧」（本 PDF 44 页）为例（原文转录）：

> **王一寧（1397—1452）** 名寧，以字行，改字文通，號節齋，仙居人。幼英敏，
> 登永樂十六年進士，授刑部主事，遷郎中。正統十三年除禮部右侍郎，景泰初轉左，
> 兼翰林學士，命入內閣預機務，尋卒，年五十六，謚文通。
> 　王公神道碑銘（芳洲文集 7/18 下）
> 　殿閣詞林記 3/32

以正文 p651「黃立極」（PDF 676 页）为例：

> **黃立極** 字中五，元城人。萬曆三十二年進士，累官禮部侍郎。天啟間魏忠賢以同鄉故，
> 擢禮部尚書，兼東閣大學士，已而為首輔，晉建極殿大學士。崇禎初定案，落職閒住。
> 　五十輔臣考 1/1
> 　明史 306/14

**字段拆解**（可直接映射到我们的 schema）：

| 索引字段 | 例子 | 对我们的用途 |
|---|---|---|
| 姓名 + 西元生卒 | 王一寧（1397—1452） | 校勘 CBDB 生卒、补 `birth/death` |
| 字 / 以字行 / 改字 | 名寧，以字行，改字文通 | 别名表、实体归一（CBDB `alt_names` 互校） |
| 号 / 室名 | 號節齋 | 字号索引互校 |
| 籍贯 | 仙居人 | `native_place` 校勘 |
| 科举年 | 永樂十六年進士 | `entry` 校勘 |
| 职官履历 | 禮部右侍郎→兼翰林學士→入內閣 | 与我们的任职段互证（尤其入阁/出阁） |
| 卒/谥 | 尋卒，年五十六，謚文通 | 离任原因、卒年 |
| 传记资料出处 | 篇名（文集卷/页）、史传（书名卷/页） | **新增「史料出处」层** |

### 3.2 出处写法

例言规定：文集资料先列篇名，再列书名与卷页（`/` 分隔）；史传类只列书名卷数；
同一资料见于两种典籍则并列。例：
「少師楊公傳（王文端公文集 37/6 下，皇明名臣琬琰錄後 1/14，國朝獻徵錄 12/28）」。

这正好补上我们现在的短板：**CBDB 有小传、没有「去哪本文集找他的墓志铭」；
索引有出处、没有结构化职官**——两者互补，不重复。

### 3.3 字号索引（一个被低估的入口）

书后字号索引按字号笔画排列，格式「字号 → 姓名 + 正文页」（实测 p43、p63 等页）。
对我们的价值：**OCR 异写治理**。我们反复遇到「字/号/别名 vs 正名」的实体问题
（如 楊士奇 CBDB 正名「楊寓」、解繉/解縉、曹霸/曹鼐），字号索引可以：
1. 把「字号」映射回正名；
2. 校验 CBDB 的 `alt_names` 是否漏收；
3. 反向帮助识别 OCR 中「以字行」的人物（例言明确「名寧，以字行」这类写法很常见）。

## 5. 对 MingOff 的六项价值（按优先级）

### 5.1 补 5 名 CBDB 未对齐人物（立竿见影）

当前正式数据有 5 名非南明人物 `cbdb_id = NULL`：
**陳山、劉宇、黃立極、王一寧、蔣德璟**（另 2 名南明已按 D15 剔除）。
本索引实测已核对 2 条：

| 人物 | 本索引条目 | 可补字段 |
|---|---|---|
| 王一寧 | 1397–1452；名寧、以字行、改字文通、號節齋；仙居；永樂十六年進士；景泰初入內閣；卒年 56，謚文通；出处 2 种 | 生卒、字号、籍贯、科举、入阁、谥、出处 |
| 黃立極 | 字中五；元城；萬曆三十二年進士；天啟間入閣、為首輔、晉建極殿；崇禎初落職；出处 2 种 | 字号、籍贯、科举、首辅/殿阁、出处 |

（另 3 人按体例应收录，需按页逐一核对；陳山：陳 p572 起；劉宇：劉 p820 起；
蔣德璟：蔣 p804 起。）

### 5.2 给 167 名内阁人物加「史料出处」层（最有产品价值）

现在抽屉只有「CBDB 小传 + 中研院一键检索」；加上本索引的
「傳記資料（篇名 + 文集/史传卷页）」，就从「人物百科」升级为
**可追溯的史料入口**：读者能看到某人有哪些墓志铭/行状/神道碑，在哪本书第几卷。
这比再堆字段更有学术价值，也符合项目「可溯源」原则（D26）。

### 5.3 字号索引 → 别名表扩充

见 3.3。可先对 167 人抽取字号，与 CBDB `alt_names`、我们已有的别名表合并，
直接减少 OCR 变体误判。

### 5.4 生卒/籍贯/登科年校勘

西元生卒年是本索引的标配字段（部分人物缺），可与 CBDB、明史互校，
产出 discrepancy 清单；对「首辅/殿阁」研究尤其有用。

### 5.5 支撑 P2「殿阁 + 首辅」

索引引用的《五十輔臣考》《殿閣詞林記》《皇明名臣琬琰錄》《國朝獻徵錄》
等，正是殿阁/首辅层（见 `docs/发展路线.md` P2）需要的史料；
可作为 P2 的校勘参考，而**不是**用来替代殿阁年表。

### 5.6 引用书目 593 种 → 未来史料库清单

15 页引用书目（版本、藏地）可直接登记为「L4 史料库」候选，
为后续部院/地方人物页提供「可以继续查什么」。

## 6. 局限与风险

| 风险 | 说明 | 对策 |
|---|---|---|
| **版权** | 1965/1978 台湾中央图书馆、文史哲出版社；中华书局 1987 影印。仍在版权期 | 只做**事实性摘要 + 出处引用**；不整段搬运小传、不把索引整体转为开放数据；如需展示原文，须获授权 |
| 质量 | 例言自承「倉促、考訂難免疏誤」；豆瓣有「資料不全，有些錯誤」评论；已有《補正》《增補》 | 与 CBDB/明史交叉；出现差异进 discrepancy，不单方面采信 |
| 扫描质量 | 无文字层，双栏小字、夹注多，OCR 错字率会高于年表 | 按《年表PDF_OCR规范》先校准、后抽检；小样本人工核对 |
| 生卒不全 | 如黃立極无生卒；部分只有年、无月日 | 维持「NULL≠0」；不补推 |
| 收录边界 | 只收「有传记资料」的人，不是全集式传记词典；不覆盖南明（与本项目 D15 一致） | 作为补充层，不作唯一人物源 |
| 工作量 | 全量 1189 页 OCR + 约 1 万条解析，成本高 | 先做定向提取（Phase 1），全量放 Phase 2 |

## 7. 落地路线与工作量

### Phase 1（建议先做）：167 名内阁 + 5 名未决人物定向提取

1. **定位**：OCR 筆劃檢字（4 页）+ 字號索引（约 70 页）+ 对应用例页；
   或直接按姓氏页段定向 OCR（约 250–350 页，MinerU 2 片）。
2. **提取**：每人一条 `person_index_src`：
   `{person, birth, death, zi, hao, native, jinshi_year, offices_summary, leave, citations[]}`，
   出处保留「篇名 + 文集/史传 + 卷/页」。
3. **接入**：
   - 新数据资产 `src/mingoff/data/person_index_src.json`（L4 校勘层，不覆盖 CBDB 小传）；
   - 抽屉新增「傳記資料（出處）」小节；
   - 5 名 CBDB NULL 人物补档案（标注来源）；
   - 生成 CBDB/明史差异清单。
4. **验收**：5 人全对；随机 20 人与原书页核对；行文为事实摘要（不搬原文）。
   **估算：0.5–1 天 OCR（排队另计）+ 1–1.5 天解析/核对。**

### Phase 2（可选）：全量索引

OCR 正文 964 页 + 字号索引 70 页（约 6 片），解析约 1 万条 →
`person_index_all.json`，服务未来部院/地方人物页。
**估算：2–3 天解析 + 抽检；收益是「全库人物出处层」。**

### Phase 3（可选）：校勘增强

合并《補正》《增補》与《明人室名別稱字號索引》，形成互校链。

## 8. 结论与建议

| 项 | 判断 |
|---|---|
| 学术价值 | **高**：明代人物传记资料的经典索引，文集出处细到卷页，补《八十九种引得》未收 |
| 对本项目价值 | **★★★★☆**：人物补全 + 出处层 + 字号索引，三点都打在现在的短板上 |
| 数据地位 | **L4 校勘/出处层**：只入「事实摘要 + 出处」，不整段搬入主数据（D26 分层原则） |
| 建议 | **采纳 Phase 1**（167+5 定向提取）；Phase 2 视人物页/部院层进度再定 |
| 风险 | 版权 > 质量 > OCR 成本；三者都可用「只做摘要 + 出处 + 人工抽检」控制 |

**一句话**：这本书不是用来「多一个数据源」，而是用来**把现有 167 人的史料出处补齐、
把 5 个空档案补上**；花 2 天左右就能见效，值得做。
