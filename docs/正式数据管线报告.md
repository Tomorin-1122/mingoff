## 二、⚠️ 源质量发现：年表存在年份空档

装配时实测（测试 `test_known_figures_present` 记录）：年表对**常年在任者并非
逐年列名**：

- 楊士奇：1403、1405–1406、1408、1410、1412–1413、1415–1421… 大量年份缺行
- 張居正：1568–1569、1572–1575 空档

**处理**：按源忠实切段，**不填补空档**（D4：空白即信息）。后果是同一人的
内阁经历呈现为多个断续段。这是年表体例（有任免动作才记）+ OCR 提取的共同
结果，不是管线 bug。

**后续待办**（阶段②）：评估"空档 ≤ N 年且两端同人同 section → 合并为一段并
降 confidence"的合并规则；合并前先抽样核对年表原书是否真的缺行（排除
OCR 丢行）。此项已列入待决问题。
