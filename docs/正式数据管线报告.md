## 六、⚠️ 数据源复核：提取层漏记「无注文人名行」（2026-10-17）

本次重做正式站时，把导出段与年表 OCR 原文逐年对照，发现**提取层有系统性缺行**，
不是"年表不逐年列名"（原第二节的解释不成立）：

| 证据 | 实测 |
|---|---|
| 正統元年（1436）年表原文列 楊士奇 / 楊榮 / 楊溥 / 張瑛 四人 | 导出仅 3 条：張瑛整人缺失，其「十、丙寅、四，卒」被挂到楊溥名下 |
| 正統二年（1437）年表原文三人俱在 | 导出 **0 条**（该年无带注文人名行，被丢弃） |
| 楊士奇 1402–1444 连续在任 | 导出被切成 11 段（1402/1404/1407/1409…） |
| 内阁条目密度 | 594 条 / 242 年 ≈ 2.5 条/年；内阁常态 3–7 人，应约 1,100+ 条 |

**根因**（`_scratch/parse_neige.py`）：

1. `if cur_person and buf` 才写条目 → **无注文的人名行整条丢弃**（最致命）；
2. 合并单元格 / 多人同行（`<td colspan=2>張 瑛 十、丙寅…`）只取到一人；
3. 殿閣表格与内阁表格混在同一 Markdown，section 判定会把注文挂错人。

**结论**：现有 360 段是"有事件年份的碎片"，不是真实任期；全朝视图的空档与断段
主要由此而来，不是前端问题。

## 七、原书复核（2026-10-17 晚）：断层不是年表体例，是解析层为主

老板质疑"同一人任职长，年表是否省略中间"，并要"回到原书确认 + CBDB 佐证"。
以册1 PDF（`D:\北山研史\明代职官\明代职官年表_第1册…pdf`，1281 页，扫描无文字层）
渲染原页核对，结论如下。

### 7.1 原书：**逐年列全名单，长任期不省略**

| 核对页 | 原书内容 |
|---|---|
| PDF 42（正文 p27）| 宣德十年（1435）/ 正統元年（1436）/ 正統二年（1437）三个年块，**每年都列** 楊士奇、楊榮、楊溥；1435 另列張瑛，1436 張瑛注「十、丙寅、四，卒」 |
| PDF 68–69（正文 p53–54）| 正德七年/八/九/十/十一/十二年逐年列名；**1515 年有 楊廷和/梁儲/靳貴/楊一清** |
| PDF 74（正文 p59）| 嘉靖九年/十年/十一年逐年列名 |
| PDF 108（正文 p93）| 崇禎元年/二年逐年列名（元年列 施鳳來 等 8 人） |

证据图（从原页裁切）：`docs/evidence/book_p42_zhengtong.jpg`、
`book_p69_zhengde10.jpg`、`book_p108_chongzhen1.jpg`。

### 7.2 OCR 件：绝大多数年份块在，个别块/行丢失

MinerU 的 `vol1_neige_a.md` 里 `<td>楊士奇</td><td></td>` 这类**空注文人名行原本存在**
（1435 年 4 人、1436 年 4 人、1437 年 3 人），但确有少量 OCR/版式瑕疵：

- **1515（正德十年）整块缺失**（原书 p69 有，OCR md 从正德九年直接跳到十一年）；
- 1554（嘉靖卅三年）年号头被拆成三个 `<td>`，正则识别不到；
- 1501 干支「辛酉」OCR 成「辛西」；个别年份块跨页/跨表被拆。

即：OCR 有损失，但**不是"长任期省略中间"**，也不是大面积缺年。

### 7.3 三方互证：中间确实没有断

**A. 原书**（见 7.1）：逐年名单连续。

**B. 《明史》卷109〈宰辅年表〉**（独立源，逐年列名）实测：
楊士奇出现 1402–1444 共 **43 年，区间内 0 缺口**；楊榮 1402–1440 共 39 年、0 缺口；
楊溥 1425–1444 共 20 年、0 缺口。

**C. CBDB**（`_cbdb/cbdb_20261010.sqlite3`，跨年型任命记录）：

| 人物 | CBDB 大学士记录 | 结论 |
|---|---|---|
| 楊士奇（CBDB 作「楊寓」66729，1364–1444）| 左春坊大學士 1420–1424；華蓋殿大學士 **1424–1444** | 至卒连续 |
| 楊榮（28347，1370–1440）| 文淵閣大學士 1420–1424；謹身殿大學士 **1424–1440** | 首尾相接至卒 |
| 張瑛（67859，1375–1436）| 華蓋殿大學士 **1426–1436** | 至卒连续 |
| 楊溥（66746，1371–1446）| 武英殿大學士 **1438–1446** | 晚段连续（1438 前无殿阁衔，看翰林/太常记录）|
| 徐階（68547）| 東閣 1552–1554 → 武英殿 1554–1564 → 建極殿 1564–1568 | 首尾相接 |
| 張居正（69011）| 東閣/武英殿 1567 → 建極殿 1570–1572 → 中極殿 1572– | 连续 |
| 劉健 / 李東陽 | 文淵閣→武英殿→謹身殿→華蓋殿，年份首尾衔接 | 连续 |

CBDB 的**局限**（不能当唯一证据）：

1. 记录常缺起讫年（None），只能作旁证；
2. 同名人物多——**本项目的 cbdb_id 有挂错**：楊士奇 28113、楊溥 199050、嚴嵩 125411
   在 CBDB 里查不到对应大学士记录（正确如 66729 / 66746；嚴嵩待定）；
3. CBDB 是二手整理，最终仍以原书逐年名单为准。

### 7.4 修订结论与建议

- 断层三源占比：**解析层 ≫ OCR 少量 ≫ 原书 0**。原书与 OCR 都提供了逐年名单，
  是 `parse_neige.py` 丢掉了无注文行、合并单元格只取一人，才把连续任职切碎。
- 因此**不必换数据源**：保留张德信册1（D21 原定源），重写表格解析即可：
  1. 以 `<tr>`/`<td>` 为单位解析（不再按文本行猜人名），**无注文也入库**；
  2. 展开 colspan/rowspan（`張 瑛 十、丙寅…` 这类合并格拆成「名 + 注」）；
  3. 年号头容错（跨单元格、干支 OCR 变体），缺块回原书页补；
  4. 用《明史》卷109/110 与 CBDB 作**校勘/断言**（discrepancy），不替代原书。
- 《明史》卷109/110 仍保留为已抓取的独立校勘源（`_scratch/mingshi_109/110.html`）。

## 九、年份头错位修复（2026-10-18）

### 9.1 问题

吳道南（万历四十一年九月入阁）只截到万历四十三年（1615），而原书万历四十四年
（1616）仍在阁；且万历四十五年（1617）七月除任期外还留下一个孤立「丁憂」事件。

### 9.2 根因（OCR 行归属）

原书万历四十四年（p87 / PDF 102）确有「方從哲 / 吳道南」两人。OCR Markdown
把**下一年的年份头并进了上一年的末行**：

```html
<td>吳道南</td><td>萬曆四十五年 丁巳 (1617)</td>
```

解析器按「年份头所在行」归属，把 1616 的吳道南记到 1617 → 1616 漏年；
1617 又单独成段（注文只有丁憂），于是出现「截到 1615 + 1617 孤立事件」。

### 9.3 全表审计结果

| 形态 | 实例 | 正确归属 | 处理 |
|---|---|---|---|
| 年份头并入上一年末行（前有注文） | 1440 曹鼐、1571 殷士儋、1583 許國 | 上一年 | 解析规则 3a |
| 年份头并入上一年末行（无注文） | 1616 吳道南 | 上一年 | 解析规则 3c（后文再出现同名） |
| 裸名行挪到年份头之前 | 1412 胡廣（原书 p19） | 下一年 | `book-patch` 补录 |
| 一格多名 = 本年整名单 | 1417/1458/1488/1518 等 | 本年 | 解析规则 3b（原书页核对） |
| 单人名 + 年份头、后无同名 | 1618/1619 方從哲 | 本年 | 解析规则 3d（原书页核对） |

两项脚本化审计（工作区 `_scratch/audit_year_merge.py`、`audit_tail_name.py`）：
年份头与其它内容同行 20 行、年份头前裸名 2 例，逐条判定。

**其余名单骤降点均回原书/《明史》核对，属真实更替**：
1448（4 人）、1513（3 人）、1539（2 人）、1587（3 人）、1626（7 人）、
1642（10 人）、1643（8 人）。張瑛 1430–1433 缺年亦为原书原貌
（1429 改南京禮尚、1434 起復），非漏行。
