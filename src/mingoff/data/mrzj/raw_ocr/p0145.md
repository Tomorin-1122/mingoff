# 明人傳記資料索引

<table><tr><td>安聲宇公石,一字鴻漸,號頤山,四川嘉定人。弘治十八年進士,選庶吉士,授吏科給事中,改兵科,屢抗疏直諫,進兵科都給事中。大禮識起,伏闕力爭,廷杖除名,卒於家。有頤山詩話。掖垣人鑑12/14明史列傳72/17明史192/11安驅、宛平人。正德十六年進士,官戶部主事,以諫大禮受杖死,隆慶中贈光祿少卿。明史192/22下守守仁,僧,富陽人,字一初,號夢觀。發跡四川延慶寺,住持靈隱。洪武中徵授僧錄司右講經,甚見尊禮,升右善世。能詩,有夢觀集。補續高僧傳25/11米米萬鐘字仲詔,號友石,關中人,徙居京師。舉萬曆廿三年進士,授永寧令,累官江西按察使,爲魏忠賢所惡,創籍。忠賢誅,起太僕寺少卿,崇禎元年卒。生平蓄奇石甚富,人稱友石先生,又善書畫,著有篆隸訂譌、北征吟。六合米侯去思記(顧慎草堂文集19/41)米仲詔詩序(大泌山房集21/10下)米女石先生墓誌(鴻寶應本8/29)啓禎野乘9/3明史288/12下父米玉(1527—1597)字璞父,號崑泉,錦衣百戶。米公馬安人壇表(大泌山房集107/17)米壽圖,宛平人。崇禎間由舉人知新鄉縣,以治行徵授御史。福王立,馬士英蔞阮大鍼,壽圖論劾之。出按四川,號召諸將,漸復川南郡縣。唐王立,撫貴州,死於賊。明史295/15下米魯,雲南霽益土知州安民女,適貴州</td><td>普安州土判官隆暢,被出。暢老,前妻子禮襲,父子不相能,米魯因令營長阿保調禮迎己,禮烝之,暢殺禮。阿保攻暢,米魯復毒暢死,遂反於普安,自號無敵天王,屢敗官軍,後爲王軾等所破,就擒伏誅。剿平貴州夷締米魯博胤事略(湘泉集24/5)羊羊可立字子喻,汝陽人。萬曆進士,擢御史,劾張居正以私憾構遼庶人獄。果擢太常卿,復以直言出爲瑞州通判卒。明史236/1下匡匡福(1335—1400),膠州人。元至正問累官河南行省參政,嘗與孛羅帖木兒擊劉福通於衛輝,見孛有異志,解甲去。尋歸太祖,爲騎尉,守東海,擊倭有功,陞副千戶,授武德將軍,世守膠州。建文二年卒,年六十六。匡福墓表(金文靖公集9/74)匡鐸字淑敎,號松野,山東膠州人。嘉靖四十四年進士,授新鄭知縣,選兵科給事中,出知大名府,以事謫河南布政司都事,歷南京戶部郎中。大名府匡公堤記(朱文轅公文集2/28)掖垣人鑑15/18下吉吉人字惟正,長安人。成化廿三年進士,授中書舍人。弘治初與劉概,湯鼐輩爲文會。四川饑,人薦鼐可爲巡按,坐朋黨削籍。明史180/20吉孔嘉,洋縣人。幼時塑父冤於巡按御史,獲釋,以孝稱。舉崇禎三年鄉試,授寧津知縣,累遷順德知府,十五年清兵臨城,孔嘉悉力拒守,城破,與妻子俱死。明史291/18下吉永祚,煇縣人,爲鳳縣主簿。謝事將歸,會流賊至,知縣棄城遁,永祚倡義拒守</td></tr></table>
