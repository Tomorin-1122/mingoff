# 明人傳記資料索引

<table><tr><td>皇明書44/21下明史283/12下明儒學案14/1董殿字碩甫,海寧人,憑子。正德十一年舉人,歷知安義、漢陽二縣,所至廉靜不苟。罷歸後,自號碧里山樵,又曰漢陽歸叟。少游王守仁之門。有碧里達存、澉浦續志。明儒學案14/1下董選字道卿,浙江蘭谿人。由太學出為南昌訓導,官至感恩知縣,以孝閼,卒年七十餘。東湖董公傳(凌瀚撰、國朝獻數錄100/57)董麟字德文,高郵人。永樂十六年進士,英宗時官修撰,劉球諫征麓川,爲王振所衡。球又言今之太常,即古之秩宗,宜慎選儒臣,使領其職。會璘乞改官太常,振遂指爲同謀,並下獄,旋殺球,璣從旁竊血裙遺球家,獄解遂歸,不復出。明史162/9董塔(1444--4526)字德美,號易直,浙江仁和人。弘治二年由國子生授安慶府通判,未幾擢太平府同知,改長沙府行守事,俱有善政,致仕卒,年八十三。董公墓誌銘(西軒效唐集錄10/11下)董興,長垣人。正統中爲右參將,從陳懋討鄧茂七,破餘黨,進都督同知。南海賊黃蕭養閣廣州,興大破之,蕭養中流矢死,餘黨皆伏誅,進右都督。後分督京營,與曹吉祥結姻,冒奪門功,封海寧伯,終宣府總兵。皇胡功臣封爵考6/88明史列傳44/5下明史175/3董檳字汝淳,麻城人。成化二十年進士,授行人,後知重慶府,歷參政,所至稱廉直,薄田敞廬以終老,爲詩類陶章,時稱董五言。古滁十思詩序(東川劉文簡公集1/11)贈董汝淳知楚雄序(柴墟文集7/7)</td><td>榮壽圖詩叙(同下7/13下)董應學字崇相,閩縣人。萬曆二十六年進士,天啓閻官太常,陳急務數事,擢太僕卿,兼河南道御史,經理天津至山海屯務,大著成效。遷工部侍郎,兼理鹽政,巡鹽御史惡其侵官,因落戰。崇禎初復官。應舉好學,善古文,居官慷慨任事,在家興利捍患,比沒,海濱人立祠祀之。有崇相集。明史242/12董懷(1465--1542)字世德,上海人,恬弟。以兄弟多習學,遂經意仕進,在家侍養持門戶,以孝友聞。平生慷慨任義,好濟人於難,喜琴,多蓄法書名畫。嘉靖二十一年卒,年七十八。董選居墓誌銘(長谷集15/1)董鏞字伯庸,長沙人。建文時御史,燕師起,請御史有志節者,時時會鏞所,誓以死報國,諸將校觀望不力戰,鏞輒露章劾之,城破被殺,夷其族。吾學編56/9皇明表忠紀2/38遜國正氣紀4/24下明史141/15董鏞(1378--1439)字孟聲,初號安邁生,晚號臛菴,仁和人。永樂二年進士,入翰林爲庶吉士,授文學官。久之薦知永豐縣,有學行,善文章,詩和平類其人,年六十二卒。董孟學墓誌銘(楊文敏公集23/17)圓圖鏡,僧,臨汾人。早悟諸經密旨,當游隰州妙懷山石室寺,至北門瓦客坡,聖洞構庵龕坐其中,驌衆徒曰,明日午時當歸,次日沐浴焚香說偈而化。明高僧傳3/14下過邇備字廷章,無錫人。擅詞翰,放情詩酒,有司薦於朝,不就。善畫,作長松特妙,自號聽松道人。</td></tr></table>
